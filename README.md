# Мини-Склад (kb99-1c-mini-sklad)

Учебная конфигурация 1С:Предприятие 8, разработанная в рамках практики (главы 1–5).
Минимальный контур складского учёта: справочники, документы.

## Что внутри

### Справочники
- **Товары** 
- **Контрагенты** 

### Документы
- **Поступление** — приход товара на склад.
- **Реализация** — расход товара со склада.

### РегистрыНакопления
- **Остатки** — учет остатков товаров.

### Отчеты
- **Обороты по товарам** — СКД-отчет с группировкой по товарам (приход, расход, остаток на конец).
- **Печатная форма «Реализация»** — вывод товарной накладной из документа.


### Интерфейс
- Подсистема **«Мини-Склад»**.
- Команды открытия справочников и документов выведены на панель подсистемы.

### Состав репозитория
- `Configuration.xml` и папки (`Catalogs`, `Documents`, `Subsystems`, `CommonModules`, `CommonPictures`, `Languages`) — выгрузка конфигурации в файлы (формат XML).
- `README.md` — это описание.
- `.gitignore` — исключение служебных и временных файлов 1С.

## Как открыть

1. Установите **1С:Предприятие 8** (подойдёт учебная версия) и **Конфигуратор**.
2. Создайте новую пустую информационную базу (без конфигурации).
3. Откройте базу в **Конфигураторе**.
4. Меню: **Конфигурация → Загрузить конфигурацию из файлов…**
5. Укажите путь к папке с выгрузкой (где лежит `Configuration.xml`).
6. После загрузки выполните **Обновить конфигурацию базы данных (F7)**.
7. Запустите **1С:Предприятие** — в интерфейсе должна появиться подсистема «Мини-Склад» с командами справочников и документов.
